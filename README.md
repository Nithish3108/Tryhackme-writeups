# OWASP Top 10 – 2025 Writeups

## What's Inside

### Application Design Flaws
- Threat modeling gaps and missing security controls at the design phase
- Insecure business logic and workflow bypass vulnerabilities
- Lack of defense-in-depth and secure design principles

### IAAA Failures
- Broken authentication and session management
- Authorization bypass and privilege escalation
- Weak identity verification and insufficient accountability/logging

### Insecure Data Handling
- Sensitive data exposure (PII, credentials, financial data)
- Insecure data storage and inadequate encryption practices
- Data leakage through logs, error messages, and improper access controls
